Minecraft Java на вашем телефоне

Лаунчер со своим запуском Java 21, без PojavLauncher. Vanilla, Fabric и Forge, моды из Modrinth и экранное управление, которое можно настроить под себя.

Android 9 и новее, arm64

Как установить

  1. Скачайте APK

    Нажмите «Скачать APK» на этой странице. Файл появится в загрузках телефона.

  2. Разрешите установку

    Откройте файл. Android попросит разрешить установку из этого источника. Если Play Protect предупредит, выберите «Всё равно установить».

  3. Выберите версию игры

    В лаунчере укажите ник и версию Minecraft. Нужные файлы игры скачаются сами, поэтому на первый раз нужен интернет.

  4. Настройте графику

    Перед первой игрой откройте Настройки и выберите пресет графики. Для большинства телефонов лаунчер уже подбирает мипмапы и разрешение сам.
