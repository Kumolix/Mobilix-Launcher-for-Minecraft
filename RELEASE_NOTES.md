version: 1.9.7.2
What's new
- Fixed: old Minecraft (1.12.2 and other legacy versions) showed the main menu shifted to the top right with cut-off buttons when the render resolution was below 100%: the game now gets the real render size at launch
- The game log now shows the screen size seen by each layer during the first 15 seconds (helps to find display problems)
