**EN: What's new**
- World backups: when you close the game the launcher saves a zip with the worlds that changed (last 3 copies per version or build). Switch and "Restore a world from backup" are in Settings; restored worlds appear next to the originals marked "copy"
- Modrinth packs: import .mrpack files through "Import files from phone storage". The launcher creates a build, downloads the files with hash checks and installs the needed game version
- Compact interface (Settings, off by default): Versions, Catalog and Builds merge into one "Downloads" section with tabs; controls layout, language and delete downloads move to Settings, which gets tabs too
- Older versions: vanilla Minecraft 1.6.1–1.7.10 can now be downloaded and launched (earlier versions are not supported yet)
- Forge and Fabric: backup mirror (BMCLAPI) for downloads, and if the recommended Forge build has no installer (HTTP 404) the launcher tries newer ones

**RU: Что нового?**
- Резервные копии миров: после закрытия игры лаунчер сохраняет zip с изменёнными мирами (последние 3 копии для каждой версии или сборки). Переключатель и «Восстановить мир из копии» в Настройках; восстановленные миры появляются рядом с оригиналами с пометкой «копия»
- Сборки Modrinth: импорт файлов .mrpack через «Импорт файлов из памяти телефона». Лаунчер создаёт сборку, скачивает файлы с проверкой хэшей и ставит нужную версию игры
- Компактный интерфейс (Настройки, по умолчанию выключен): Версии, Каталог и Сборки объединяются в раздел «Загрузки» с вкладками; раскладка управления, язык и удаление скачанного переезжают в Настройки, где тоже появляются вкладки
- Старые версии: ванильный Minecraft 1.6.1–1.7.10 теперь можно скачать и запустить (более старые пока не поддерживаются)
- Forge и Fabric: запасное зеркало (BMCLAPI) для загрузок, а если у рекомендуемой сборки Forge нет установщика (HTTP 404), лаунчер пробует более свежие
