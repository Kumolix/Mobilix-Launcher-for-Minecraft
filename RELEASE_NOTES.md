version: 1.7.0
EN: What's new
- Faster first launch: multi-threaded download (16 threads), can be turned off in Settings → Launcher
- A warning before the first launch: downloading takes a few minutes
- Fixed: the download no longer resets when the screen is rotated
- Better support for older devices: the app now installs on 32-bit devices and explains clearly why the game cannot run there
- Automatic GitHub releases for important versions
