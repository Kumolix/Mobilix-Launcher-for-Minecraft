version: 1.9.1

**EN: What's new**
- Builds: a new "Builds" tab in the catalog. Each build has its own folder (mods, worlds, settings) and version; the pencil opens a catalog for that build; pick a build at the bottom of the version list
- Catalog: tabs in two rows, new Datapacks tab (can be added to a world right after download), a button that collapses search and tabs, Fabric/Forge centered
- Mods: mods for another loader are disabled automatically (mods-disabled folder); mods from the catalog are updated for your game version and loader, required dependencies are downloaded, and you get a warning if something is missing. Switch in Settings
- Forge: fix for the 1.20.1 launch hang (module conflict with the vanilla jar); Forge 1.12.2 installs even when the installer has no versionInfo
- Update notice appears only when a new release is published; Social page now has a website link and icons, the menu shows the current language
- Language menu with Chinese (translations are being added, untranslated text stays in English)
- Windows in launcher style, new website: kumolix.github.io/Mobilix-Launcher-for-Minecraft

**RU: Что нового?**
- Сборки: новая вкладка «Сборки» в каталоге. У каждой сборки своя папка (моды, миры, настройки) и версия; карандаш открывает каталог для этой сборки; выбрать сборку можно внизу списка версий
- Каталог: вкладки в два ряда, новая вкладка «Датапаки» (после скачивания можно добавить в мир), кнопка, которая сворачивает поиск и вкладки, Fabric/Forge по центру
- Моды: моды другого загрузчика отключаются сами (папка mods-disabled); моды из каталога обновляются под вашу версию игры и загрузчик, обязательные зависимости докачиваются, а если чего-то не хватает, будет предупреждение. Переключатель в Настройках
- Forge: исправление зависания при запуске 1.20.1 (конфликт модулей с ванильным jar); Forge 1.12.2 ставится, даже если в установщике нет versionInfo
- Уведомление об обновлении появляется только при выходе релиза; в «Соцсетях» появились ссылка на сайт и иконки, в меню видно текущий язык
- Меню выбора языка с китайским (перевод дописывается, непереведённое показывается по-английски)
- Окна в стиле лаунчера, новый сайт: kumolix.github.io/Mobilix-Launcher-for-Minecraft
