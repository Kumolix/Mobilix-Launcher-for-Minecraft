version: 1.7.1
EN: What's new
- The app now targets a modern Android version, so Play Protect no longer warns that it "was built for an older version of Android"
- Release build (not debug), still signed with the same permanent key, so it installs over the previous version
- Privacy Policy added (no data is collected), link on the Social page
- Forge installation now runs inside the built-in Java (required by modern Android)
- Multi-threaded download (16 threads), can be turned off in Settings → Launcher
- Warning before the first launch; download no longer resets when the screen is rotated
- The app can now be installed on 32-bit devices and explains why the game cannot run there

RU: Что нового?
- Приложение теперь рассчитано на современный Android, поэтому Play Protect больше не пишет, что оно «создано для более ранней версии Android»
- Релизная сборка (не debug), подписана тем же постоянным ключом, ставится поверх прежней версии
- Добавлена политика конфиденциальности (данные не собираются), ссылка на странице «Соцсети»
- Установка Forge теперь идёт во встроенной Java (так требует современный Android)
- Многопоточная загрузка (16 потоков), отключается в Настройки → Лаунчер
- Предупреждение перед первым запуском; загрузка не сбрасывается при повороте экрана
- Приложение ставится на 32-битные устройства и объясняет, почему игра там не запустится
